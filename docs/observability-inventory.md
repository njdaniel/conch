## Web client

**Page ring** means the last 100 events total, kept in memory until reload or eviction and copied into a report only when the user sends it (`web/src/diagnostics.ts:1-15,65-77`, `web/src/Report.tsx:48-71,114-129`). **Panel session** means the Voice diagnostics panel starts closed. On open it reads immediately and then every two seconds, with at most one in-flight read per track. It keeps the latest report per current track for deltas and clears the samples on close. It renders missing metrics as unavailable. The desktop renderer can show companion share stats. Its native call quality display says a newer helper is required (`web/src/voice/stats.ts:221-298`, `web/src/voice/VoiceDiagnostics.tsx:22-77,83-93`, `web/src/voice/sdk.ts:1789-1804`).
