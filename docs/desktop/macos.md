# Conch unsigned macOS preview

The preview runs on Apple silicon with macOS 15 or later. Download the
`unsigned-preview` artifact from the CI run you want to test, unzip it, open
the `.dmg`, and drag **Conch** into **Applications**.

Open **Conch** from **Applications**. If macOS blocks it because it cannot
verify the developer, close the alert, then go to **System Settings → Privacy
& Security** and click **Open Anyway** for Conch. Confirm in the next dialog.
Use this option only for a preview you downloaded from the Conch CI run.
