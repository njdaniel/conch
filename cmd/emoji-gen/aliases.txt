# Conch's own table of the shortcode aliases people type from Slack, GitHub
# and Discord (issue #1036). Written for Conch, not copied from gemoji or any
# other list: that data carries a licence, and this table does not.
#
# One alias per line: <alias> <code points of the emoji>. An alias is
# lower-case a-z, 0-9, '_', '+' or '-'. The code points are the emoji's
# sequence with or without U+FE0F; it must be a fully-qualified sequence of
# the pinned emoji-test.txt, or cmd/emoji-gen fails naming the alias.
#
# Aliases reach web/src/emoji/catalog.json only. They are names for typing and
# search: the reaction-key table (pkg/schema/emoji_catalog_gen.go) is
# unchanged, and what a reaction carries is always the emoji itself.
